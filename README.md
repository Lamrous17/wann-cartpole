## Краткое описание проекта

В рамках лабораторной работы реализован нейроэволюционный алгоритм **Weight Agnostic Neural Networks (WANN)** для решения задачи обучения с подкреплением **CartPole-v1** из библиотеки Gymnasium.

Цель работы — исследование возможностей нейроэволюционного подхода к обучению агента без традиционной оптимизации весов нейронной сети. В процессе работы реализована эволюция структуры сети, проведено обучение агента, выполнено сравнение с базовым методом, исследовано влияние гиперпараметров, проведена абляция алгоритма и анализ устойчивости полученного решения.

---

## Цель работы

Реализация и исследование нейроэволюционного алгоритма WANN для решения задачи обучения с подкреплением.

---

## Решаемая задача

В проекте рассматривается задача управления агентом в среде **CartPole-v1** библиотеки Gymnasium.

Необходимо обучить агента удерживать шест на тележке максимально долго, используя нейроэволюционный алгоритм WANN без обучения весов сети градиентными методами.

---

## Возможности проекта

Проект включает:

* реализацию алгоритма WANN;
* обучение агента в среде CartPole-v1;
* сравнение с базовым методом (Random Agent);
* исследование влияния гиперпараметров;
* механистическую абляцию (отключение структурных мутаций);
* анализ устойчивости к шуму во входных данных;
* анализ динамики сложности сети;
* визуализацию структуры сети;
* сохранение обученной модели.

## Запуск проекта

```bash
python main.py
```

После запуска программа:

* обучает агента с использованием алгоритма WANN;
* строит графики обучения;
* сравнивает результаты с базовым методом;
* выполняет гиперпараметрические эксперименты;
* проводит анализ устойчивости;
* сохраняет обученную модель в файл `wann_best_cartpole.pkl`.
